Five beats.
One receipt.

QorTime turns the end of a console match into a signed JSON receipt. The free verifier checks it in your browser. A hosted referee countersign — Verified Match — is early access and Stripe test mode until KYC.

01 Capture 02 Challenge 03 Co-sign 04 Seal 05 Verify
  1. 01

    Capture

    The agent on the player’s PC reads the Madden scorebug off the capture card, digit by digit, and locks a score only when consecutive frames agree. The on-site scorebug is an illustration, not a league mark.

    See it on the homepage

  2. 02

    Challenge

    The referee sends a nonce. The player pauses and enters OPTIONS plus four buttons. That pattern has to show up in the DualSense HID log and on video within 600 ms. A replay does not get a second pattern from the past.

    See it on the homepage

  3. 03

    Co-sign

    About every four seconds the agent sends a rolling hash of frames and inputs. The referee timestamps and countersigns each checkpoint. A receipt written after the match cannot carry those earlier signatures.

    See it on the homepage

  4. 04

    Seal

    At the final whistle each running agent signs the result and the referee seals it. If both players run agents and their timelines agree, the trust tier is dual-attested. One agent is single-attested.

    See it on the homepage

  5. 05

    Verify

    Paste the JSON into the verifier. It checks signatures, the checkpoint chain, and the challenges locally. The verdict is VERIFIED, PARTIAL, or FAIL. The receipt file is not uploaded for that check.

    Open the verifier · demo receipt JSON

  6. +

    Verified Match

    Separate from free self-verify. A $9.99 list price for a hosted referee countersign after a completed match. Labeled TEST / early access until business KYC. The Payment Link is Stripe test mode. It does not take real money.

    Early accessPricing

What a receipt does not prove

  • Account sharing. Who is physically holding the controller.
  • Collusion. Both players agreeing to throw or fake a match.
  • Anything outside the capture card’s field of view.
