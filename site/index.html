How a moment gets sealed

  1. 01

    Capture

    The agent on the player's PC reads the scorebug from the capture card and logs the DualSense USB input reports, the same controller that plays over Bluetooth.

  2. 02

    Challenge

    At kickoff, halftime and the end, the referee sends a random nonce. The player pauses and enters the pattern. It must show up in the input log and on video within 600 ms.

    OPTIONS←→✕↓
  3. 03

    Co-sign

    Every ~4 seconds a rolling hash of frames and inputs goes to the referee, which timestamps and countersigns it. A receipt forged later can't carry signatures from the past.

  4. 04

    Seal

    At the final whistle each player's agent signs the result and the referee seals it. If both players run agents and their timelines agree, it's dual-attested.

  5. 05

    Verify

    Paste the JSON into the verifier. It checks every signature, the checkpoint chain and the challenges, all in your browser, and returns a verdict.

Illustrative values, not a real match.

One verdict. Two tiers.

VERIFIED

Every signature, checkpoint and challenge checks out against the pinned referee key.

PARTIAL

Signatures are valid but something is missing, like an unpinned referee key or a skipped challenge.

FAIL

A signature, the chain or a challenge doesn't hold. Don't pay out.

For money-match & tournament platforms

Verify in one call

The reference verifier ships as a Python CLI and a small browser JS module. Run it on every result before releasing escrow. A hosted verify API is roadmap.

qortime verify r.json --referee-pub <hex>

Fewer "he lied about the score" tickets

A sealed receipt replaces screenshots and arguments with something a machine can check. Disputes that remain are about things a receipt can't see, and we list those plainly.

Open format

JSON, canonicalized (JCS), Ed25519 signatures. Spec and schema are in the repo, MIT licensed. Roadmap: TPM-held keys (PHASE2).

Honest limits

A VERIFIED receipt says the score on the screen was read by an agent with a live human on that controller at those times. It does not prove:

  • Account sharing: who is physically holding the controller.
  • Collusion: both players agreeing to throw or fake a match.
  • Anything outside what the capture card saw.
